Charaf Eddine Benarab

I build the software layer that sits between a language model and the thing it’s supposed to be useful for. Context engineering, retrieval, agent execution graphs, and the deployment plumbing (Docker, FastAPI, Postgres, Neo4j) that turns a checkpoint into something a company can run air-gapped and trust. Based in Algiers, sometimes Kuala Lumpur.

I got here backwards from most people doing this now: five years in a computational intelligence lab in Chengdu on early Transformers and sentiment analysis, before “prompt engineering” was a phrase anyone used. Small models, frozen backbones, squeezing signal out of representations instead of scaling past them — that habit never really left.

What I actually work on

Context engineering over brute-force scale. Most of what I build treats the LLM as a stateless reasoning kernel, not a container of memory. Token-budget enforcement, KV-cache tricks, prefix-caching, sliding-window attention — the goal is always the same: get a small model to punch above its parameter count by giving the surrounding software more of the burden.

Agentic execution graphs. Stateful multi-agent systems as deterministic DAGs (LangGraph, mostly), with explicit routing and error handling instead of hoping the model self-corrects. If a system’s behavior can’t be traced node by node, I don’t trust it in production.

Hybrid retrieval. RAG that pairs vector search (Qdrant) with symbolic structure (Neo4j knowledge graphs), because pure nearest-neighbor retrieval quietly degrades the moment your corpus has real structure — patents, citations, compliance literature.

Air-gapped and on-prem deployment. A lot of my client work happens under hardware or compliance constraints that rule out hitting a hosted API. That forces good engineering: everything has to run local, cheap, and observable.
